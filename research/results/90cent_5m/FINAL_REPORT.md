# Фінальний backtest: купівля 5m UP/DOWN біля 90¢

## Коротка відповідь

Якщо купувати першу сторону, чий ask піднявся до рівня 90¢, то paper win rate становить:

- **Варіант A, taker:** **89.79%** — 4,266 перемог із 4,751 fills; 95% CI **88.90–90.62%**.
- **Варіант B, maker pullback на 89¢:** **85.20%** — 2,793 перемоги з 3,278 fills; 95% CI **83.95–86.38%**.

Але обидва варіанти мають від'ємний EV у протестованій моделі.

## Дані та settlement

- Період: **2026-08-25 — 2026-08-31**.
- 3,070,974 recorder rows, із них 1,534,482 для 5m.
- 5,127 ринків побачено.
- **5,085** ринків мають age-299 snapshot і підтверджений результат Gamma.
- 42 неповні ринки виключено.
- BTC, ETH, SOL.

Winner взято з офіційного resolved Gamma `outcomePrices`, а не з локального Chainlink recorder. Це критично: у recorder **3,878 із 5,085** ринків мали `terminal_cl == strike_cl`, а Chainlink-inferred winner не збігався з Gamma у **2,126** випадках.

Для taker fee використано Gamma `feeSchedule` усіх ринків:

```text
fee/share = 0.07 × price × (1 − price)
```

Maker fee — 0.

## Варіант A — rising-cross taker

Правило: перший UP або DOWN ask, який переходить з `<90¢` до `≥90¢`; купівля за фактичним записаним best ask і утримання до settlement.

| Метрика | Результат |
|---|---:|
| Complete markets | 5,085 |
| Signals / fills | 4,757 / 4,751 |
| Wins / losses | 4,266 / 485 |
| Win rate | **89.79%** |
| 95% CI | 88.90–90.62% |
| Average actual entry | **90.992¢** |
| Break-even WR після fee | **91.564%** |
| Gross EV/share | **−1.200¢** |
| Net EV/share | **−1.772¢** |
| Середній net PnL для 50 shares | **−$0.886** |

Через 1-second resolution ask інколи перестрибував 90¢. Розподіл actual fills:

| Entry | Fills |
|---:|---:|
| 90¢ | 2,766 |
| 91¢ | 840 |
| 92¢ | 448 |
| 93¢ | 281 |
| 94¢ | 173 |
| 95–99¢ | 243 |

### Тільки fills рівно по 90¢

- 2,766 fills;
- 2,450 wins, 316 losses;
- win rate **88.58%**;
- 95% CI **87.34–89.71%**;
- gross EV **−1.424¢/share**;
- після taker fee: **−2.054¢/share**.

Отже, навіть для фактичної ціни рівно 90¢ історичний win rate був нижчим за 90%.

## Варіант B — maker pullback

Правило: після rising-cross 90¢ поставити fixed post-only bid 89¢; fill лише якщо на наступному snapshot ask повернувся до 89¢ або нижче. Без repricing.

| Метрика | Результат |
|---|---:|
| Signals | 4,757 |
| Quote-touch fills | 3,278 |
| No-fill orders | 1,479 |
| Fill rate | **68.91%** |
| Wins / losses | 2,793 / 485 |
| Win rate | **85.20%** |
| 95% CI | 83.95–86.38% |
| Entry | 89¢ |
| Break-even WR | 89.00% |
| EV/share | **−3.796¢** |
| Середній PnL для 50 shares | **−$1.90** |
| Median time-to-fill | 4 s |
| P90 time-to-fill | 30 s |

Maker pullback має сильну adverse selection: сторона, яка досягла 90¢, але потім програла, майже неминуче повертається через 89¢ і заповнює наш ордер. Частина майбутніх переможців не повертається — їхні orders залишаються без fill. Тому maker fill rate нижчий, а conditional win rate гірший.

Щоб компенсувати результат лише rewards/rebates, maker-виплата мала б у середньому перевищувати **3.8¢ на кожен filled share**. Така виплата не гарантована і в PnL не включалась.

## Висновок

**Ціна біля 90¢ справді означає приблизно 90% історичних перемог, але цього недостатньо для прибутку.**

- Taker платить у середньому 90.99¢ плюс fee, а виграє 89.79% випадків.
- Точні 90¢ fills виграли лише 88.58%.
- Maker pullback купує дешевше по 89¢, але відбирає переважно траєкторії, що розвертаються, тому WR падає до 85.20%.

За цим семиденним sample **проста купівля на рівні 90¢ не має позитивного edge**.

## Обмеження

- Snapshots мають 1-second resolution.
- Taker fill припускає виконання за записаним best ask із позитивною displayed quantity.
- Maker quote-touch — оптимістична верхня межа, без queue position і trade prints.
- Maker rewards/rebates не монетизовані.
- Період тесту — сім днів; це не гарантує майбутній результат.
