## Результат 1: структура ймовірностей РЕАЛЬНА (валідовано out-of-sample)

Fair-value grid P(лідер виграє), train (14 днів) → test (7 днів, окремо):

| T \| \|dist\| | ≥10 bps train→test | ≥15 bps train→test |
|---|---|---|
| T ≤ 240s | 79.9% → 73.9% | 90.8% → 76.1% |
| 240 < T ≤ 480 | 85.1% → 78.3% | 92.1% → 86.1% |
| 480 < T ≤ 720 | 92.5% → 85.2% | 97.2% → 93.8% |
| T > 720s | 97.5% → **93.4%** (n=1291) | 99.5% → **98.6%** (n=4503) |

Монотонно, стабільно, Brier 0.161 проти бази 0.179. Калібрування top-квінтиля: pred 0.981 → emp 0.974.
**Фізична закономірність існує.** Це не артефакт тренду (баланс UP/DN у тесті 52/48).

## Результат 2: але ГРОШІ з цього витиснути taker'ом НЕ ВИХОДИТЬСЯ

Бектест входів по реальних trade prints (тест-тиждень, комісія taker врахована):

**v1 "застарілий fair"** (fair з часу T, купуємо дешевше fair−3c):
- 21,361 філів, WR 64.3%, **EV = −$0.016/share → сумарно −$340**
- Дешевизна проти застарілого fair = adverse selection: поки ми дивились на T, ціна вже пішла проти лідера

**v2 "свіжий fair"** (fair перераховано на секунду КОЖНОГО принта):
- Лише **48 філів на 1,885 ринків** (можливості майже зникають) 
- З них WR 35.4% замість очікуваних ~92% → **EV = −$0.088**
- Світ: sweep по margin {3,4,6c} × floor {3,8,15bps} — токсичність скрізь

## Чому так: два механізми

1. **Книги ефективні**: боти в Polymarket рахують fair value з того ж Binance-фіду. Застарілі котирування живуть мілісекунди.
2. **Binance ↔ Chainlink basis**: рідкі "дари" (ціна набагато нижче нашого fair) — це моменти, коли Chainlink (джерело РЕЗОЛЮЦІЇ) розходиться з Binance. Ринок дивиться на Chainlink і правий. Ми купуємо сміття. Симетрично: наші 93%-збіги лейблів ламаються саме на цих подіях.

## Висновки та що реально залишається

❌ **Не працює**: тaker-стратегія "купити лідера дешевше fair" — edge з'їдений ефективністю книг + basis-токсичністю. Малопробні "100%/95% WR" з минулих аналізів — селекція + stale pricing.

✅ **Залишається реалістичним:**

1. **Maker-стратегія з ребейтами**: Polymarket повертає мейкерам 100% taker-комісій (`makerRebatesFeeShareBps=10000`). Заробіток = spread + ребейти, а не напрямок. Потрібна симуляція черги/інвентаря — історично не відтворюється, тільки live-paper тест.
2. **Chainlink-native фід**: якщо наш pricer використовує ТОЙ САМИЙ джерело, що резолюція (Chainlink Data Streams), basis-токсичність зникає. Гіпотеза для paper-тесту: чи лишаться тоді дешеві принти, і чи стануть вони прибутковими.
3. **Арб UP+DOWN ≠ $1**: сканер sum(bid_UP+bid_DOWN)>1 або sum(ask)<1. Рідко, але безризиково.
4. **Інші серії**: 5m ринки / інші активи можуть бути менш ефективними (перевірено лише 15m btc/eth/sol).
5. Напрямний сигнал 5m свічок (52–55% з попереднього дослідження) — як фіча в pricer, не як standalone стратегія.

- Ребейти не рятують: середній ребейт ≈ pool/maker_volume ≈ $66k/$3.1M ≈ 2.1% номіналу
